# StorageLens — Frontend

**Cost intelligence for cloud storage.** StorageLens is the frontend of the
Intelligent Cloud Storage Cost Optimizer: a dark-first, dashboard-dense console
for reviewing S3 storage tiers, recommendation experiments, policy rules and
their compliance conflicts.

StorageLens is an independent cost-analytics project. It is not an AWS
product, and it is not affiliated with or endorsed by Amazon Web Services.

## Setup

```bash
npm install
```

Point the app at the deployed backend by creating a `.env` file (see
`.env.example`, which is committed for reference):

```env
VITE_API_BASE_URL=https://<api-id>.execute-api.ap-south-1.amazonaws.com
```

- The value is the API base URL (no `/documents` suffix, no trailing slash).
- It comes from the `DocumentsApiEndpoint` output of the
  `intelligent-storage-cost-optimizer` CloudFormation stack.
- If the variable is unset, the app runs in offline mode: experiment pages and
  the dashboard (both driven by committed experiment artifacts) still work, and
  live data panels show their empty states.
- `.env` is git-ignored and is never committed.

## Data honesty contract

- **LIVE** data (documents, access statistics, aggregation) comes from the
  backend API only, and is labelled with a `LIVE` badge.
- **EXPERIMENT** data (all cost and savings figures) comes from
  `src/data/experiments.json`, a committed artifact generated by
  `scripts/build_frontend_experiment_data.py` in the repository root. Every
  such number is labelled with an `EXPERIMENT` badge, and the two kinds are
  never mixed in a single figure.
- The app never invents metrics: panels show real values, loading skeletons,
  or explicit empty states — nothing in between.

## Live cost estimate panel

The dashboard's *Live storage cost estimate* computes a **client-side
estimate** from live document metadata (`file_size`, `current_storage_class`)
using the rates in `src/utils/pricing.ts`. That module mirrors — and is
tested against — the optimizer's own pricing snapshot
(`optimization/pricing.json`: ap-south-1, snapshot date surfaced in the
panel, AWS Price List API-validated values). It is a display helper, not a
second pricing authority: figures are labelled as estimates, storage charges
only, never an AWS invoice, and the panel shows no savings figure (savings
exist only in EXPERIMENT-labelled panels).

## Theming

Dark is the default and primary experience; a light theme is available via
the toggle in the top bar. The theme resolves before first paint from
`localStorage` (`storagelens.theme`, falling back to the OS preference) via
the inline script in `index.html`, and is applied as `data-theme` on
`<html>` with app-level state in `src/hooks/useTheme.tsx`. Every color in
the app is a token on `:root` re-derived in the `:root[data-theme="light"]`
block, so charts and components pick the theme up automatically; in-segment
label ink uses the `--tier-ink-*` tokens.

## Rebuilding the experiment data bundle

From the repository root:

```bash
python scripts/build_frontend_experiment_data.py
```

This regenerates `frontend/src/data/experiments.json` from the experiment
artifacts in `experiments/`.
